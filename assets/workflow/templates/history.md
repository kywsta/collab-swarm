# Delivery history

What this repository has delivered, compacted from the plans that built it. Each row names the commit that still holds its plan, so any file of it can be read back:

```bash
git show <commit>:<plans>/<slug>/requirements.md
```

The board reads `Slug` and `Status`: a `delivered` or `superseded` row is done, exactly as a complete plan on the default branch is. Everything else here is for the reader.
